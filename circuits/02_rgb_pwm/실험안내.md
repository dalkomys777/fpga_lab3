# RGB LED PWM 사전 시뮬레이션

매뉴얼 20번 회로의 RTL 3개, TB, XDC 및 simulation.json을 작성했습니다.
Icarus 결과: LAB3_RGB_PWM_PASS checks=2. 종료 시각 4851 ns.
Vivado XSim과 보드 실험은 아직 수행하지 않았습니다.

## 매뉴얼 대비 변경
RTL과 XDC는 매뉴얼과 같습니다.
TB의 버튼 입력 및 리셋 해제를 하강 에지로 옮겨 상승 에지의 DUT 처리와 경합하지 않도록 했습니다.
기대값은 유지하고 검사별 기대값, 측정값 및 시각 출력을 추가했습니다.
따라서 아래 시각은 현재 저장한 TB 기준입니다.

## 실행
상위 LAB3.code-workspace에서 Terminal → Run Task...를 선택합니다.
- 02_rgb_pwm - 02 Simulate
- 02_rgb_pwm - 03 Open waveform

## 파형에 추가할 신호
- tb_rgb_pwm: clk_50mhz, rst_p, button_r, button_g, button_b, led_r, led_g, led_b
- tb_rgb_pwm.dut: level_r, level_g, level_b
- tb_rgb_pwm.dut.u_pwm_r: count
level과 count는 부호 없는 십진수로 표시하면 편리합니다.

## 주요 검사 구간
| 검사 구간 | level_r, level_g, level_b | 10회 검사 중 HIGH 횟수 |
|---|---|---|
| 4071~4251 ns | 2, 5, 8 | R=2, G=5, B=8 |
| 4671~4851 ns | 3, 5, 8 | R=3, G=5, B=8 |

클록 주기는 20 ns이며 각 검사 구간은 20 ns 간격의 10회 샘플입니다.
PWM 주기는 200 ns입니다. 첫 조건의 HIGH 폭은 R=40 ns, G=100 ns, B=160 ns입니다.
두 번째 조건에서는 R만 60 ns로 늘고 G와 B는 유지됩니다.
각 출력은 4비트이며 HIGH일 때 F, LOW일 때 0으로 표시됩니다.

증빙 로그와 VCD는 상위 evidence/02_rgb_pwm/icarus_baseline에 저장했습니다.
정상 파형 확인 후 매뉴얼의 수정 및 복구 실험을 진행합니다.
